# Emergency Department Optimisation

This project develops a quantitative optimisation model of an emergency department where doctors, nurses, beds and other critical resources are allocated efficiently to patients whilst maintaining patient flow under uncertain conditions.

## Aim

The aim is to create a simulation that models patient arrivals, acuity, treatment times, waiting queues and resource availability. The simulation is used to investigate how resources can be allocated efficiently to reduce patient waiting times and congestion.

## Current work

- Patient generation
- Queue management
- Resource allocation

## Run

```bash
python -m pip install -r requirements.txt
python source/run_patient_generation.py
```
